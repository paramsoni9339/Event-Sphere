## ✨ Features

### 🎫 For Event-Goers
- **Discover Events**: Browse and search through a diverse range of events
- **Trending Events**: Stay updated with what's hot and happening
- **Smart Ticketing**: Easy ticket purchase and management
- **Venue Explorer**: Find and explore various event venues
- **Community**: Connect with other event enthusiasts
- **Personal Dashboard**: Track your tickets and upcoming events

### 🏢 For Venues
- **Venue Profiles**: Showcase facilities and amenities
- **Capacity Management**: Display and manage venue capacity
- **Upcoming Events**: Highlight scheduled events
- **Reviews & Ratings**: Build credibility through user feedback

### 👑 For Admins
- **Comprehensive Dashboard**: Monitor platform activities
- **Event Management**: Create and manage events
- **User Management**: Handle user accounts and permissions
- **Analytics**: Track sales and engagement metrics

## 🚀 Tech Stack

- **Frontend**: Next.js 13+, TypeScript
- **Styling**: TailwindCSS, Radix UI Components
- **UI/UX**: Lucide Icons, Framer Motion animations
- **Theme**: Dark/Light mode support
- **Authentication**: Built-in auth system

## 🛠️ Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/EventSphere.git
   ```

2. **Install dependencies**
   ```bash
   pnpm install
   ```

3. **Run the development server**
   ```bash
   pnpm dev
   ```

4. **Open [http://localhost:3000](http://localhost:3000)**
